Joe's Budget — preparação para GitHub Pages

Carregar TODOS os ficheiros desta pasta para a raiz de um repositório GitHub. Em Settings > Pages, escolher Deploy from a branch, main, /(root). Abrir o endereço HTTPS e adicionar ao ecrã principal do iPhone pelo Safari.

IMPORTANTE: os dados são guardados apenas no navegador/dispositivo. Não há sincronização entre equipamentos. Fazer cópias de segurança regularmente. O site é publicamente acessível; não adicionar dados pessoais ao código-fonte.
